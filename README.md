## TL;DR

同一组量价拥挤度因子（20 日动量、量能异动、跳跃频次、量价资金流），四个散户占比梯度排列的市场，同协议横截面检验——**符号随边际定价者翻转**：

| 市场 | 散户成交占比（量级） | 拥挤组合 − 冷门组合 | t 值 | 符号 |
|---|---|---|---|---|
| **A 股全市场**（5,083 只） | ~70–80% | **-1.18%/月** | -1.32 | 负 |
| **Crypto 全体**（58 对） | 高 | -1.18%/月 | -0.61 | 负，不显著 |
| **美股小盘 S&P 600**（592 只） | ~30–40% | +0.30%/月 | +0.74 | 不显著 |
| **美股大盘 S&P 500**（503 只） | ~20–25% | **+0.91%/月** | **+1.91** | **正** |

拥挤度信号不可跨市场平移：A 股的"韭菜指数"逻辑搬到美股大盘等于做空动量。

## 关键结果

### 1. 主检验（合成拥挤分，月末截面，持有次月）

A 股拥挤组合绝对年化 **-11.7%**——拥挤识别的不是"跑输的组合"，是"未来烧钱的组合"。

### 2. 加密货币：效应只在订单流原生数据中显形

量价代理因子在 Binance 现货上全部失效。唯一显著信号是 **taker 主动买入占比偏离**（MA20 − MA120），且呈域特异性：

| 检验 | 结果 |
|---|---|
| 主流币（12 只） | **-5.25%/月，t = -2.59** |
| ⊥ 动量正交化 | -4.47%/月，t = -2.07（不是反转马甲） |
| 周频 | 失效（t = -0.27）→ 慢均值回归，摩擦友好 |
| 逐年 | 2022 -8.8% / 2024 -14.3% / 2025 -2.4%，五年四年为负 |

**信号一行版**：`crowding = MA20(taker_buy_quote / quote_vol) − MA120(taker_buy_quote / quote_vol)`，做空高偏离 / 超配低偏离，月频，主流币域。

### 3. A 股涨停事件研究：磁吸 → 反转的完整生命周期

50.9M stock-days、4.9 万次涨停收盘事件：

| 窗口 | 涨停股 | 全市场 | 相对 |
|---|---|---|---|
| T+1 | **+2.02%** | +0.04% | 磁吸延续 |
| 5 日 | +1.36% | +0.23% | 延续 |
| 20 日 | +0.03% | +0.85% | 反转开始 |
| 60 日 | **-1.68%** | +2.26% | **-3.9pp 完整反转** |

20 日相对差**五年全负**（2022 -1.9pp … 2026 -1.0pp）。涨停计数单因子：月频 t = -1.31，**周频 t = -2.72**——alpha 集中在散户追板入场的那几周。

### 4. 机制：三条腿的凳子

| 市场 | 涨跌停 | T+1 | 做空通道 | 预测符号 | 实测 |
|---|---|---|---|---|---|
| A 股 | ✓ | ✓ | ✗ | 负 | 负 ✓ |
| Crypto 主流 | ✗ | ✗ | 部分 | 弱负 | 弱负（仅订单流）✓ |
| S&P 600 | ✗ | ✗ | ✓ | 近零 | 不显著 ✓ |
| S&P 500 | ✗ | ✗ | ✓✓ | 正 | 正 ✓ |

涨跌停把价格出清改写成排队出清（磁吸），T+1 锁住追高资金的持有期，无做空修正让拥挤只能被时间消化（阴跌）。人群结构是放大器，不是开关。

## Replication

数据全部来自公开 API，无需任何 token：

| 数据集 | 源 | 接口 |
|---|---|---|
| A 股日线 | 新浪财经 | `CN_MarketDataService.getKLineData`（`scale=240, datalen=1023`） |
| 宇宙名单 | 新浪财经 | `Market_Center.getHQNodeData`（`node=hs_a`） |
| 美股日线 | Yahoo Finance | `v8/finance/chart`（`range=5y&interval=1d`） |
| 成分表 | Wikipedia | List of S&P 500 / 600 companies 快照 |
| Crypto 日线 | Binance | `api/v3/klines`（字段 7 = quote_vol，字段 10 = taker_buy_quote） |

```bash
python src/download_ashare.py    # ~5200 只, 30min
python src/download_us.py        # S&P500 + S&P600, ~3min
python src/download_crypto.py    # 58 对, ~1min
python src/backtest_crowding.py  # 四市场主检验 + 事件研究
```

**已知数据源坑**：东方财富 push2 接口会按 IP 限流（HTTP 501），新浪 K 线单次上限 1023 根（A 股窗口因此为 51 个月 vs 美股 60 个月）。

## 与 Bagholder 50（冷西西）的关系

本研究起因于对[冷西西指数](https://indices-toocoldcc.pages.dev/)（Bagholder 50，四因子散户反向指数）的逆向分析。本文**不使用其任何私有数据**，仅将其作为独立管道的外部效度参照：其规则公开（2026-07-10）后，指数在样本外继续以 -28.2% 对基准 +7.2% 运行，与本文 A 股结论方向互证。研究方法学上的一个副产品发现：其"订阅墙"在数据发布侧实现（公开 JSON 无成分股），仅韭菜50 agent feed 全量公开。

## 局限（诚实清单）

1. 美股用现任成分股回测历史——幸存者偏差抬高动量侧收益，+0.91%/月应视为上界（但符号与 Jegadeesh–Titman 共识一致）
2. A 股偏差方向相反（缺漏的恰是退市的拥挤股），-1.18%/月为下界
3. 无成本模型；crypto 主流币月频摩擦估 5–15bp/边，相对信号幅度充裕
4. t 统计量未做组合形成日聚类校正，以逐年同号、正交化、跨域一致性辅助支撑
5. F3 阈值未做波动率调整（跨市场严格版应改 2σ 自适应）
6. 主流币子样本 12 只，三分位下统计功效有限
